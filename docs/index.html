Features

The essentials of mind mapping in one small, fast app. The map lays itself out; you add the ideas.

Automatic layout

Topics arrange themselves on both sides of the centre. Branches keep their side; Balance Map evens them out.

Keyboard first

Every command has a shortcut and is also in a menu. F1 lists them all.

Relationships

Curved arrows across branches, one- or two-way, in eight colours and three line styles.

Markdown notes

A note per topic with headings, lists, tables, task lists and code, with a preview.

Markers and icons

Priorities, progress and ten icons, readable without colour.

Search

Topics, notes and links in all maps, as you type and accent-insensitive.

Several maps per file

Related maps live together as sheet tabs in one document.

Encryption

Optional AES-256 with a password, in a standard format that 7-Zip opens too.

PNG export

A whole map as an image at twice screen resolution, white or transparent.

Privacy

A desktop app in the old sense: it works on your files and nothing else.

  • Almost no network. No telemetry, no account. At start MindBuzz asks GitHub whether a newer version exists, sending only its name and version; it downloads nothing. A link opens in your browser only when you click it.
  • Nothing left behind. No settings file, no registry entries, no recent-files list. Your documents, and while you edit, a recovery file next to them.
  • An open file format. One .mbz file per document: a ZIP archive with JSON inside, documented in the repository.
  • Safe with your work. Saves never overwrite half a file, everything can be undone, and a recovery file brings back unsaved changes after a crash.

Download

Builds for each release are on GitHub. There is nothing to install.

Windows

Download MindBuzz.exe from the latest release and run it.

Latest release

Windows 10 or 11, 64-bit

macOS

Download MindBuzz.app for your Mac and move it to Applications. The app is not signed, so run this once before the first start:

xattr -dr \
  com.apple.quarantine \
  /Applications/MindBuzz.app
Latest release

macOS 14 or later, Apple silicon or Intel

Linux

Download MindBuzz for your processor (x64 or ARM64), make it executable and run it:

chmod +x MindBuzz
./MindBuzz
Latest release

64-bit Linux with an X11 or Wayland desktop

From source

With the .NET 10 SDK:

git clone https://github.com/vanlil/MindBuzz.git
cd MindBuzz
./run.sh                  # build and start (run.cmd on Windows)
./build.sh --publish      # the release build for this machine, in artifacts/

How it is made

MindBuzz is vibe coded: an AI coding agent (Claude Code) wrote it from a detailed written specification, while its author decided every feature and reviewed and tested every change on Windows, macOS and Linux.

  • Specification. CLAUDE.md describes what the app does and why. The non-functional requirements collect what was learned about building cross-platform Avalonia apps, written to be reused.
  • Built with .NET 10, Avalonia, Semi.Avalonia, CommunityToolkit.Mvvm, Markdig, AvaloniaEdit and SharpZipLib. More than 500 automated tests run on every build.

Questions

Is MindBuzz free?

Yes. It is free and open source under the GNU Affero General Public License v3. There is no paid edition and no account.

Does it work offline?

Yes. MindBuzz never connects to the internet. It sends no telemetry and checks for no updates.

Which systems does it run on?

Windows 10 and 11 (64-bit), macOS 14 or later on Apple silicon and Intel, and 64-bit Linux (x64 and ARM64) with an X11 or Wayland desktop.

How are mind maps stored?

Each document is one .mbz file: a ZIP archive with JSON inside, optionally encrypted with AES-256. MindBuzz keeps no settings and no data of its own.
